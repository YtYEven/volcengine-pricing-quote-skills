# 取价规则（pricing_lookup）

> 从本地《火山产品刊例价》CSV 提取单价的统一规则。

## 一、数据源

- 目录：`../火山产品刊例价/`
- 文件命名：`<产品中文名>_官网刊例价_*-定价-YYYY_M_DD HH_MM_SS.csv` 或 `<产品中文名>_定价-...csv`
- 一产品一份。74 个文件。

### 新鲜度检查

开干前先看：`ls -lt ../火山产品刊例价/ | head -5`
- 最新文件 mtime 距今 ≤ 30 天 → 直接用。
- > 30 天 → 提示用户："本地刊例价已 X 天未更新，建议先跑 `更新火山引擎产品刊例价` skill 刷新。" 用户确认继续后再用。

## 二、产品 → CSV 文件名映射

按 [product_mapping.md](product_mapping.md) 拿到火山产品中文名后，去 CSV 目录里 `grep`：

```bash
ls ../火山产品刊例价/ | grep "<火山产品中文名>"
```

如：火山产品名 "云数据库 MySQL 版" → 文件 `云数据库 MySQL 版_官网刊例价_*.csv`。

模糊匹配规则：
- 名字含空格的产品（如 "云数据库 MySQL 版"）→ 用 `grep -F` 防误判。
- 产品有多份（如 ByteHouse 云数仓 vs ByteHouse 企业版）→ 按业务场景选；不确定时备注两份并请客户确认。

## 三、读取 CSV

用**文件读取能力**读全文件(不要只读 head,因为表格有多档可能在文件后半段)。CSV 结构:
- 表头：`地域`、`实例规格`、`vCPU`、`内存`、`包月单价`、`包年单价`、`按量单价` 等。
- 多区域/多档：每个组合一行。
- 部分快照提取的 CSV 用空白行分段多张子表。

## 四、单价选取规则

### 1. 地域过滤

默认 **华东2（上海）**。CSV 中文写法可能是 "华东2" / "华东2(上海)" / "cn-shanghai" / "上海"。优先匹配；找不到 → 用 "华东1（杭州）" 或 "华北2（北京）" 兜底，备注说明。

### 2. 计费方式

| 客户标注 | 取价列 |
| --- | --- |
| 包1年（默认） | "包年单价" 或 "包1年" 列；月折算 = 包1年 / 12 |
| 包月 | "包月单价" |
| 按量 | "按量单价" / "按小时" / 按用量列 |
| 火山仅提供按量 | 强制按量，备注"火山侧无包年定价" |

**Excel 中的月折算**：取 CSV 上的 1 年总价 → 在 Excel 用公式 `=年价/12` 而不是预先算好。让用户能点 cell 看到来源。

### 3. 规格匹配

按 [spec_mapping_rules.md](spec_mapping_rules.md) 确定的火山规格（如 `ecs.g4i.xlarge`）去 CSV 找精确匹配。CSV 行通常是：
```
华东2(上海),ecs.g4i.xlarge,4,16,xxx,yyyy,zzzz
```
取对应列单价。

### 4. 阶梯/分段定价（CDN、TLS、OSS 流量、DDoS 弹性等）

不要硬塞一个数。在 Excel 的 "按量计费" sheet 列：
- `计费维度`（GB / 万次 / Mbps / 小时）
- `单价`（写第一档单价或所有档位用 `;` 分隔）
- `单位`
- `估算说明`（写假设量 + 第一档计算式）

### 5. 多档套餐（WAF、DDoS 高防、云防火墙）

直接取 CSV 上的"标准版/高级版/企业版/旗舰版"对应单价。客户没说版本 → **默认企业版**（中位），备注。

### 6. 派生维度（实例 + 存储）

ECS / RDS 这种：CSV 通常只有"实例小时价 / 月价"，**不含磁盘**。磁盘单独从 `弹性块存储_*.csv` 取。Excel 里：
- `实例月单价` = CSV 实例价
- `存储月单价` = 磁盘单价 × 容量（用公式：`= 单GB价 * 容量`）
- `单台月价` = `实例月单价 + 存储月单价`（公式）

### 7. 找不到对应规格

如客户要 5C20G（非标）：
- 向上取最接近的标准规格（8C32G / 4C16G 取大）。
- 备注："原 5C20G 已按火山 8C32G 取价（无完全匹配规格）。"

## 五、特殊产品的取价细节

| 产品 | 特殊处理 |
| --- | --- |
| 弹性块存储 | 单价是 元/GiB/月。Excel 容量×单价用公式。系统盘 PL0 0.5；数据盘 FlexPL 1.0。 |
| 对象存储 TOS | 存储/请求/流量分开。默认只取标准存储容量；其他在备注说明"未计入"。 |
| 日志服务 TLS | 写入(0.85 元/GB)/索引(0.35 元/GB)/存储(0.0115 元/GB/天) 必须分项列在"按量计费" sheet。 |
| CDN | 按月流量阶梯。客户没量级 → 假设 1 TB/月 取第一档，备注。 |
| 云数据库 Redis | 分片版 vs 主备版单价不同。客户没说 → 默认主备版（双副本）。 |
| Kafka / RocketMQ | 实例规格 + 存储两段。 |
| 火山方舟 / VikingDB | 全按量 token / CU 计费。直接列单价 + 计费维度。 |
| ByteHouse | 计算 CU + 存储 GiB/小时 分开。 |

## 六、报价单元转换速查

- 元/小时 → 元/月 = `× 24 × 30`（用 30 天月，CSV 上写明就以 CSV 为准）
- 元/小时 → 元/年 = `× 24 × 365`
- 年单价 → 月折算 = `/ 12`
- GiB/小时 → GiB/月 = `× 720`

所有换算在 Excel 用公式，**不要**在 markdown 或思考里算好再填死值。

## 七、取不到价时的回退

1. 在 CSV 里找最接近的档位；备注差异。
2. 如该产品根本没有 CSV（如刚发布的）→ 在 Excel 行的"火山规格"列写 "待补"，备注"刊例价 CSV 缺，需访问官网定价页或联系火山销售确认"。
3. 不要凭印象/历史报价编单价。
